# The skill adds one to five images, only when they help

The agent decides how many trace maps a PR gets, aiming for whatever makes the PR easiest for a human to understand: one image for a small change, one long trace split into highlighted segments for a large feature, one image per parallel flow, or a comparison for a bug fix or refactor whose route changed. The hard limit is five images per PR; if more seem necessary, the agent makes the trace coarser (for example directories instead of files) rather than adding images. If the PR does not suit a trace map, it gets none. When the skill runs at all is left to the target repo's `AGENTS.md`/`CLAUDE.md`; this repo's README provides an example sentence instead of the skill triggering itself.
